# University of Bath – NSS 2025 Data Science Analysis

**Institution:** University of Bath  
**Module:** CM52055 – Analytic Software Technologies  
**Project:** National Student Survey (NSS) 2025 Analysis

## Overview
This project analyses the National Student Survey (NSS) 2025 dataset using Python and data science techniques.

The analysis explores:
- Student satisfaction across UK universities
- Subject popularity and student demand
- Institutional performance benchmarking
- Strategic opportunities for degree programme development
- Scalable data science approaches for larger datasets

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Recommendation
The analysis recommends Business Studies as a promising degree programme for the University of Southampton, based on student demand, satisfaction and provider coverage.

## Project Structure
- `Jupyter_Notebook.ipynb` – Data analysis and implementation
- `AST_CW_Data_Science_Report.pdf` – Detailed project report

## Academic Context
Developed as part of the MSc coursework at the University of Bath.
